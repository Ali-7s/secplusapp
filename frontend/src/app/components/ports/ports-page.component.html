How it works

  • Each table is a network and a list of rules to write. Choose the protocol and type the port from memory: the question never gives you the number.
  • Random tables are new every time: different ports, hosts, addresses and wording, with your weakest ports asked most, so there is nothing to memorize. Some rules name the protocol and some only describe the job.
  • Written scenarios are fixed networks that cover every port and protocol in this trainer.
  • Your first check of a random table counts toward your port levels, just like a drill. A written scenario counts only the first time, since after that you may just remember it. A port counts as right only if every rule using it had both the protocol and the port right.

How it works

  • Learn a set of four to eight ports that do the same kind of job, with a memory hook for each.
  • Drill it in rounds of {{ ROUND }}: port to name, name to port, TCP or UDP, the secure replacement, and which port a situation needs.
  • A right answer moves a port up a level, but only once an hour; a miss drops it two. Recalling a port minutes after reading it only shows it looks familiar, so mastered (level 4) means you got it right in four sittings at least an hour apart. Come back later to move ports up.
  • Set rounds slip in three ports from sets you have already started, so you cannot answer by elimination, and older sets keep coming back. Rounds ask about your weakest ports most.
  • Answers also count in the Reference deck's Review mode, which brings ports back on later days so they stay learned.
