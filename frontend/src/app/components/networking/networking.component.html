Why this section exists

Security+ assumes you already know how networks work (CompTIA recommends Network+ first). Many exam topics, such as VLANs, screened subnets, ARP poisoning, firewall rules and secure ports, only make sense once the basics click. This path teaches just the parts the exam leans on, in the order that makes them stick.

  • Do them in order the first time. Each lesson builds on the one before.
  • Each lesson ends with a short check so you know whether it landed.
  • Every device and protocol lesson ends with how to secure it. That practice has a name: hardening.
  • Come back to one lesson whenever a flashcard does not make sense. Cards link to their lesson.
