psychology How to remember it

  • The mask values come from switching on one more bit at a time, from the left:

  • Block size = 256 minus the mask's last number. 256 − 224 = 32, so a /27 holds 32 addresses.
  • Each step down in prefix doubles the block: /30 is 4, /29 is 8, /28 is 16, /27 is 32, /26 is 64, /25 is 128, /24 is 256.
  • Usable = block − 2. The first address names the network and the last is the broadcast.
  • Powers of two: 2, 4, 8, 16, 32, 64, 128, 256. Every block size is one of them.

format_list_numbered The method in five steps

  1. Hosts to prefix. Find the smallest block whose usable count covers the hosts you need. 50 hosts: a /27 gives only 30, a /26 gives 62, so use a /26.
  2. Prefix to block size and mask. /26 means a block of 64, and 256 − 64 = 192, so the mask is 255.255.255.192.
  3. Blocks start at multiples of the block size. For 64: .0, .64, .128, .192. A subnet can never start anywhere else.
  4. Network, broadcast and usable range. The network is the block's first address and the broadcast is the next block's start minus one. Usable is everything in between. The default gateway is usually the first usable address.
  5. Several subnets in one network: do the biggest first, and start each new subnet right after the previous broadcast (previous broadcast + 1). Biggest first keeps every block on its proper boundary.

search Which subnet is this address in?

Example: 192.168.1.130/26.

  1. /26 means blocks of 64.
  2. Blocks start at 0, 64, 128 and 192. 130 is between 128 and 191, so it is in the block that starts at 128.
  3. Network 192.168.1.128, broadcast 192.168.1.191, usable .129 to .190 (62 hosts).

Two addresses are in the same subnet only if they land in the same block. 192.168.1.70/26 (block .64) and 192.168.1.130/26 (block .128) are not, so they need a router between them.
